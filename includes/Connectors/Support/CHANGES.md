# Changes and clarifications to vendors-contract.md (V0)

Nothing was renamed. Read these before you code; they are clarifications and additive extras.

1. **Exceptions.** `api()->get/post/...` throw `ApiException` (`->error(): ConnectorError`, `->response(): ?ApiResponse`) for every failure. Let it propagate out of
   your public methods: in production the registry hands out `GuardedConnector`, which turns it into the `ConnectorError` / `SendResult::failure` / failed `TestResult`
   the engine expects. `ApiConnectorContractTestCase` wraps your connector in the same way. In your own unit tests that call `send()` and friends directly, wrap first:
   `$connector = GuardedConnector::wrap( $connector );` (or call `ErrorBridge::toError( $throwable, 'Name' )`). Catch `ApiException` yourself only when a failure is part
   of normal flow (a 404 on lookup: prefer `$options['allow'] = array( 404 )`).
2. **Visibility.** `meta()`, `baseUrl()`, `authStrategy()`, `identify()`, `fieldCatalog()`, `mappings()` are `abstract protected` in the base (widen to `public` if you like).
   `findExisting()` and `send()` come straight from `ConnectorInterface` (public). Do not define methods named `api`, `connectorMeta`, `listTaxes`, `redactionValues`, `idempotencyHeader`,
   `vendorError`, `credentialDefinition`, `defaultHeaders`: the base owns them (you may override the protected ones that are meant to be overridden: `defaultHeaders`, `vendorError`,
   `idempotencyHeader`, `credentialDefinition`, `redactionValues`).
3. **ConnectorMeta** takes extra named arguments after the contract ones: `hosts: array` (fixed hosts, `*.example.com` allowed; required unless `merchantHost`), `merchantHost: bool`
   (address typed by the merchant: private hosts refused unless the filter allows), `contractVersion`. `RateLimitHints( requestsPerSecond, concurrency, requestsPerMinute, requestsPerDay )`:
   the per-minute and per-day caps are enforced by the pacer (RATE-001 with the wait).
4. **Taxes.** Implement `public function listTaxCodes( Connection ): array|ConnectorError` returning `array{code,name,rate_percent}`. The base provides `listTaxes()` (the name the REST layer calls) on top of it.
5. **OAuth.** `OAuthConnector::oauthProvider(): OAuthProvider`; `organisations( Connection ): array` (may throw ApiException); `selectOrganisation( Connection, string $id ): array`.
   `OAuthTokenManager::accessToken( Connection, ?OAuthProvider = null )` / `refreshNow( Connection, ?OAuthProvider = null )`. Client id is read from `$connection->config( 'client_id' )` (then secret),
   client secret from `secret( 'client_secret' )`; other names via `OAuthConfig( clientIdKey:, clientSecretKey: )`. The redirect address is ONE stable address for the site: `OAuthRedirect::uri()`.
   Return `new OAuth2Auth( $this->oauthProvider() )` from `authStrategy()`; the base gives it the token manager.
6. **Credential fields.** `CredentialField` has `type` (`text`, `password`, `select`, `textarea`, `url`, `number`, `display`), `options`, `group` (`connection`, `app`, `advanced`). `Support\CredentialFields` has ready-made
   fields (`clientId()`, `clientSecret()`, `privateKey()`, `apiKey()`, `username()`, `password()`, `address()`, `choice()`). For a sign-in style the base appends a read-only `redirect_uri` field (`display`).
7. **Export connectors** extend `Export\AbstractExportConnector` (itself an `AbstractApiConnector`): implement `meta()` (auth `AuthStyle::ExportFile`), `fieldCatalog()`, `mappings()`, `exportFormat()`, `appendOrder()`, `finish()`.
   In `appendOrder` call `$batch->add( $item->id, $item->entityId, $row )` (or `$batch->leaveOut( $item->id, $item->entityId, $reason )`). In `finish` read `$batch->included()` and return `new ExportFile( contents: $text, format: $this->exportFormat() )`.
8. **ConnectorDependencies** has one trailing optional property `pacer` (shared pacing store). Use `$this->deps->clock`, `->http`, `->logger`, `->tokens`, `->exports`.
9. **Folder of export files** is `uploads/estasoft-sync/exports/{random32}/` (inside the folder `Core\DataEraser` already removes on uninstall), not `estasoft-sync-exports`.
10. **Test helpers** land with step 7: `Tests\Support\ApiFakeServer`, `Tests\Support\ApiTestKit`, `Tests\Contract\ApiConnectorContractTestCase`.
11. **JWT algorithms.** `OAuthConfig( jwtAlgorithm: 'RS256'|'RS384'|'RS512'|'PS256'|'PS384'|'PS512'|'ES256'|'ES384'|'ES512' )`; `jwtMode: 'assertion'` (Salesforce: grant_type=jwt-bearer&assertion=) or `'client_assertion'` (NetSuite: grant_type=client_credentials&client_assertion_type=...&client_assertion=). Extra header fields (`kid`) go in `jwtHeaders`.
12. **More public helpers** (all additive): `AbstractApiConnector::authStyle()` (public), `ErrorBridge::toError( Throwable, 'Name' )`, `Xml::encode( array, root )`, `Redaction` (secrets removed from messages; `$this->api( $c )->redaction()->add( $value )` for a tenant id you learn at run time), `CredentialFields::choice( name, label, array $options /* value => label, NOT a list */, selected )`.
13. **Sign-in flow the UI follows** (document for your connector): `POST /connections` with the app details saves the connection as `needs_reconnect` without calling the vendor; `POST /connections/{id}/oauth/start` gives the vendor address; the vendor sends the browser to `OAuthRedirect::uri()`; `GET /connections/{id}/oauth/organisations` calls your `organisations()`; `POST /connections/{id}/oauth/organisation {id}` calls `selectOrganisation()`, then `test()` (your `identify()`), and activates the connection when it passes. A vendor without a tenant concept returns ONE entry from `organisations()` (the account) and the screen picks it. Keep the tenant id in the config keys `selectOrganisation()` returns, and send it from `defaultHeaders()` or `baseUrl()`.
14. **`ConnectorsModule` wraps** every `AbstractApiConnector` in `GuardedConnector` (and, for the authorization-code style, in `GuardedSignInConnector`). `$registry->get( 'xero' )` is the wrapper; `->inner()` is your object. Do not test against `instanceof XeroConnector` on registry objects.
15. **Client credentials / JWT (`cloud_app`)**: `POST /connections` tests like a key connector (token request through `OAuth2Auth`, then `identify()`) and saves only when it passes. A connection that is not saved yet has id 0; the token manager keeps its token in memory for that request.
16. **Export additions (answers to V8).** `ExportFormat( ..., bom, charset, rawBytes )`: with `rawBytes: true` the contents are already encoded (Windows-1252, UTF-16LE) and the store adds nothing. `finish()` may return `ExportFile::fromPath( $this->deps->exports->workFile(), $format )` after writing a stream (the store moves the file, adding the UTF-8 mark only when the format asks). `ExportBatch::iterate()` streams the included rows one at a time (a batch of 10,000 orders never sits in memory; `rows()` and `included()` still load everything); `includedIds()` and `count()` read no rows. `$batch->connection()` is the connection (config, settings) in `finish()` and in `appendOrder()`. `ExportFile( attachments: [ [ 'name' => 'Masters', 'filename' => 'masters.csv', 'mime' => ..., 'contents' => ... ] ] )` stores a second file; the Exports screen gets it as `attachments` of `ExportFileInfo` and downloads it with `GET /exports/{id}/download?part=1`. `send()` is one file check (`ExportStore::hasItem()`) however many orders wait; the batch given to `appendOrder()` holds only that order. Refunds are accepted when the connector declares `EntityType::Refund` in `meta()->entities`.
17. **OAuth additions (answers to V1 and V2).** The extra query values of the vendor's redirect (`realmId`, `businessId`; short plain values, at most 10) are saved before `organisations()` is called under `$connection->config( 'oauth_callback' )` (array). `OAuthConfig( refreshOnDemand: true )` for tokens that live minutes: the scheduled task leaves them to the next call and only refreshes when the refresh token runs out within 7 days. `protected function limitsFor( Connection ): RateLimitHints` on `AbstractApiConnector` (default `meta()`) gives plan-dependent caps to the pacer. A connector that can also connect without a sign-in page defines `public function requiresSignIn( Connection ): bool` (default true when absent): when false, `POST /connections` tests it with a token request and activates it, and `oauth/start` answers SYNC-CFG-004.
18. **Catalog forms (coordinator, 2026-11-02).** `GET /catalog` rows and every entry of `variants` carry `credential_fields` (`CredentialFieldDef[]`: name, label, secret, required, hint, default, type, options, group), `can_sign_in` and `auth_style` (the `AuthStyle` value). Built by `Jobs\Connections\CatalogForms` from the registry's `credentialFields()`; connectors are constructed only for the rows that are available and selectable, and the answer is kept in a transient (`estasoft_sync_catalog_forms_{md5(version|locale)}`, 10 minutes; locale is in the key because labels are translated). A secret field or a `password` field never carries a default. A row with variants has no form of its own (the variants do); a row that is not available (SMACC, not built yet) has `credential_fields: []`, `can_sign_in: false` and the style of its connection method. `ExportFileInfo.attachments` is always sent (`{name, filename, size_bytes}`); there is no `download_url`: files are fetched through the signed-in request (`GET /exports/{id}/download?part=N`).
19. **Review fixes (independent reviewer, 2026-11-02).**
    - Export: `ExportService::create()` closes only the queue items the file dealt with (`closeBatch( $id, $itemIds )`); an order added between the snapshot and the close stays for the next file. The creation lock lives 300 seconds.
    - OAuth: margin is `min( 300, lifetime / 2 )` (`OAuthTokenManager::margin()`, secret `oauth_lifetime`), also for the waiting worker; the refresh lock lives 90 seconds; `RefreshTask` counts a connection only when it is due, rotates its start by one run's worth each run, and uses half the life as the window for tokens that live less than 20 minutes.
    - Token errors: `TokenErrors::holds()`. Only a JSON `error` of `invalid_grant`, `invalid_client`, `unauthorized_client` (and `access_denied` for a sign-in code) holds the connection. HTML, empty and error-less answers and `server_error` are SYNC-NET-002 and change nothing (a 404, 405 or 410 page for the token address is SYNC-AUTH-001, still not held).
    - `HostPolicy` fails closed (no hosts and no `merchantHost` allows nothing, also for token and sign-in addresses); `OAuthConfig` has `merchantHost`; merchant names are resolved and every A/AAAA address is checked; numeric forms, trailing dots, zone ids refused; the checked addresses are pinned with `CURLOPT_RESOLVE` through `http_api_curl` (cURL transport only; `HostPins`). **Three providers set `merchantHost: true` because the merchant types their address: `OracleFusionOAuth`, `SapS4HanaOAuth`, `SuiteCrmOAuth` (one argument each).** Every other provider already names its hosts.
    - `RequestPacer` reserves the slot, then counts the daily quota, and gives both back when it stops a call with SYNC-RATE-001.
    - `BasicAuth` fails when a configured user field has no value (the condition was inverted); `ApiRequest::withHeader()`, the client and `HeaderKeyAuth`/`BearerAuth` remove CR, LF and NUL from headers. Pasted secrets were already trimmed on save by `ConnectionService::cleanSecrets()`.
    - `OAuthState::consumeAny()` and `consume()` take the state atomically (`AtomicKeyValueStore::take()`, implemented by `TransientStore`: one `DELETE`, the caller whose delete succeeded keeps the value). The callback also refuses a browser that is signed in as somebody other than the person who started the sign-in (`get_current_user_id()`, else the logged-in cookie).
    - `SessionAuth` logs in under a lock and `onUnauthorized()` compares session ids (see BUILDING.md).
20. **CSV writer and the call sites that must switch (V8's files, not edited by V0).** `Support\Export\CsvWriter` is the one writer; `ExportFormat::writer()` builds it with the format's delimiter. Tally is XML and already escapes and strips control characters through `ExportShared\XmlBuilder::escape()`: no change. These must switch to `CsvWriter` (use `CsvWriter::SPACE` so the importer does not read a quote as text):

    - DATEV: `includes/Connectors/Datev/DatevColumns.php`, `DatevColumns::record()` (the `TEXT` branch builds the quoted field by hand: use `CsvWriter::field( $value, true )` for text and the raw value for numbers, dates and accounts) with the writer from `ExportFormat::csv( 'DATEV', delimiter: ';' )->writer( CsvWriter::SPACE )`; `DatevColumns::headings()` is fixed text (no change). `includes/Connectors/Datev/DatevConnector.php`, `header()` (the `$text( ... )` closure: company name, dictation, origin and consultant text come from the merchant's settings). Caller of `record()`: `DatevPostingWriter.php:170`.
    - Anywhere else that joins fields with `implode( ',' | ';' )` or quotes by hand in `includes/Connectors/{Sage50,Datev,ExportShared}` (none found besides the above; `LedgerExportConnector::mastersList()` writes plain text for display, not an import file).
21. **Review-fix batch (briefs/review-fixes/v0.md, 2026-11-02).**
    - `OAuthConfig( minTokenAgeSeconds: 0 )` (V7 reads this, Exact Online: 570 for its 600 second tokens). Time to refresh = the later of "margin before expiry" (`min( 300, lifetime / 2 )`) and "issued + minimum age"; a minimum longer than the token's life counts as the whole life. The age is `life - seconds left` (the stored `oauth_lifetime`; unknown life means no restriction). Applies to `accessToken()`, to the waiting worker's reuse, to `RefreshTask`, and to the 401 path: `OAuth2Auth::onUnauthorized()` returns false (no retry, no token request) while the token is too young, `OAuthTokenManager::mayRefreshNow()` is the question, and `refreshNow()` returns the token in hand instead of asking the vendor. A connector with its own 401 handler (`ZohoTokenAuth` calls `refreshNow()` directly and is safe) should ask `mayRefreshNow()` before retrying.
    - `ApiClient`: an absolute URL in a path is refused with SYNC-VAL-002 unless scheme, host and port equal the base URL's, or its host is a declared fixed host (https, port 443 or the base port). Checked in `url()` before the request is built, so before `AuthStrategy::apply()`. `HostPolicy::assertFollowable()`. A merchant-typed host follows links on its own origin only.
    - `AbstractApiConnector::ping()`: one `GET` of `ConnectorMeta::$pingPath` when declared (new optional constructor argument, last), else `identify()`. Every connector should declare `pingPath` or override `ping()`.
    - Catalog: front matter `unavailable_reason:` becomes the row field `unavailable_reason` (written only when set; `GET /catalog` always sends a string; `CatalogEntry.unavailable_reason?`, also on a variant when its document has one). The generator warns for `available: false` without a reason. `smacc.md` got its reason (V0 added the line; the hand-written `needs` is unchanged).
    - Generator: `hosts` entries are trimmed and lower-cased, a `*.domain` pattern is accepted and kept in the list with its `*.` (documented in `CatalogEntry.hosts`, the README index and BUILDING.md), and an entry that is not a host name or a clean pattern is reported.
