# External services

Generated by `php bin/generate-external-services.php` from `docs/connectors/*.md`; do not edit by hand (CI runs it with `--check`). It backs the `== External services ==` section of `readme.txt`, which WordPress.org requires for every service a plugin contacts (guideline 6).

The plugin has no Estasoft server, no telemetry, no analytics and no update check. It contacts only the system the merchant connects, only after the merchant has entered that system's credentials, and sends only the data the merchant's mapping selects. Each row below says which hosts are contacted, what is sent and when. "Data sent" and "When" are numbered in the same order and come from the section "Data sent and when" of the connector's own document. A host written `*.example.com` stands for the address of the merchant's own account at that vendor; "the address you enter" means a server the merchant runs or rents.

32 systems are contacted over the network, 3 make a file and contact nothing, 2 cannot be selected yet.
